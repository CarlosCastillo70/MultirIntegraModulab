## ✅ Checklist d'Inici

Abans de començar, assegura't de tenir:

- [ ] Accés a Oracle (Modulab)
- [ ] Accés a MySQL (MultiR)
- [ ] .NET Framework 4.8 instal·lat
- [ ] Permisos adequats a les bases de dades
- [ ] Editor de codi (Visual Studio recomanat)
