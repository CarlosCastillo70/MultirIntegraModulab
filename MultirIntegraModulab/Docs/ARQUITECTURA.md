## Principis SOLID Aplicats

### 1?? Single Responsibility Principle (SRP)
```
? Cada Use Case té una única responsabilitat
? ValidarMostraUseCase ? Només valida
? ProcessarMostraPositivaUseCase ? Només processa positives
```

### 2?? Open/Closed Principle (OCP)
```
? Obert a extensió: Fàcil afegir nous Use Cases
? Tancat a modificació: No cal canviar el codi existent
```

### 3?? Liskov Substitution Principle (LSP)
```
? Qualsevol implementació de IModulabRepository es pot substituir
? Els Use Cases no coneixen les implementacions concretes
```

### 4?? Interface Segregation Principle (ISP)
```
? Interfaces específiques per cada servei
? ILoggerService, IConfigurationService, etc.
```

### 5?? Dependency Inversion Principle (DIP)
```
? Les capes externes depenen de les internes
? Application depèn de Domain (interfaces)
? Infrastructure implementa les abstraccions
```
